## 2. Objetivo da Task
Criar a biblioteca visual local da feature com componentes reutilizáveis, Tailwind e linguagem Material Design 3, sem adicionar biblioteca UI pesada.

---

## 3. Descrição Detalhada
- Criar componentes em `components/ui/*.tsx` conforme Tech Spec e design system.
- Implementar estados acessíveis: loading, erro, vazio, selecionado, desabilitado, foco e reduced motion.
- Usar classes Tailwind e tokens CSS globais, sem snapshot visual como contrato de teste.
- Componentes devem receber props explícitas e não conter I/O.
- Manter dimensões estáveis em chips, skeletons, botões e cards.

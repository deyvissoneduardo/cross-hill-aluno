## 2. Objetivo da Task
Criar a camada isolada de mapeamento de erros públicos e antiabuso genérico para o POST de agendamento.

---

## 3. Descrição Detalhada
- Criar helpers de erro de domínio público para duplicidade, indisponibilidade, payload inválido e limite antiabuso.
- Criar limitador server-side substituível por fake nos testes.
- Garantir que mensagens públicas permaneçam genéricas e não revelem regra operacional.
- Não criar o Route Handler POST nesta task.

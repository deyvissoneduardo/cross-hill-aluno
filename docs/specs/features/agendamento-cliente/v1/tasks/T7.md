## 2. Objetivo da Task
Implementar o Route Handler POST público para payload válido, normalização server-side e retorno pendente.

## 3. Descrição Detalhada
- Criar `app/api/public/agendamentos/route.ts` com método `POST`.
- Validar payload no BFF e normalizar novamente nome/telefone.
- Aplicar antiabuso antes da transação.
- Delegar criação para `agendamentoStore.criarSolicitacaoAgendamento`.
- Retornar `SolicitacaoAgendamentoDTO` com `AGUARDANDO_CONFIRMACAO` sem dados de terceiros.

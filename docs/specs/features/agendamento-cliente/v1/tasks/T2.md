## 2. Objetivo da Task
Criar os tipos e DTOs públicos da feature sem incluir campos privados de terceiros ou detalhes administrativos.

---

## 3. Descrição Detalhada
- Criar `app/agendamento/types.ts` com modelos de domínio e DTOs públicos da Tech Spec.
- Separar campos internos de Firestore dos DTOs retornados para o cliente.
- Evitar qualquer campo que exponha lista, quantidade, telefone ou nome de terceiros.

## 2. Objetivo da Task
Criar a base do fluxo interativo com provider/reducer e primeira etapa de identificação sem conta.

---

## 3. Descrição Detalhada
- Criar reducer e provider locais em `app/agendamento/state/*`.
- Criar `AppointmentFlow` inicial renderizando `IdentificationStep`.
- Validar nome e telefone antes de avançar.
- Garantir ausência de campos de conta, senha, login ou perfil.
- Não persistir estado em storage, cookie ou URL.

- [ ] Dados válidos avançam para a próxima etapa em memória.
- [ ] Reducer não permite revisão com seleção incompleta.
